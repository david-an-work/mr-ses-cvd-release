# mr-ses-cvd

Code and derived results for:

> An DH. *Conditional Instrument Strength and the Attribution of Socioeconomic Effects on Cardiovascular Disease: A
> Mendelian Randomization Study.* Unpublished manuscript.

A preregistered two-sample mendelian randomization (MR) and multivariable MR (MVMR) study of four socioeconomic
measures (educational attainment, income, occupational status, area deprivation) and four cardiovascular outcomes
(coronary artery disease, peripheral artery disease, heart failure, any stroke), using public GWAS summary statistics
only. No individual-level data were used.

- **Registration:** OSF https://osf.io/k7dcm (registered 2026-10-08) and the linked deposit https://osf.io/usz4x holding
  the frozen plan files, which are the canonical registered record. `ANALYSIS_PLAN.md` here is identical to the registered plan v1.0
  (SHA-256 `832d832d9072cd997de3bef9f0429edfe243db4838bd54ed2009ee5b99f8487b`).
- **Departures from the plan:** `results/logs/DEVIATIONS.md` (dated).
- **Archived release:** v1.0.0, Zenodo doi:[10.5281/zenodo.23966018](https://doi.org/10.5281/zenodo.23966018).

## What is in this repository

| Path | Contents |
|---|---|
| `R/` | Analysis pipeline (R 4.5.3) and two Python verification scripts (`03c`, `03e`) |
| `R/utils/` | Shared helpers: file registry and column mapping (`sumstats_registry.R`), harmonization, MR methods, outcome readers |
| `renv.lock`, `renv/` | Locked R package versions (restore with `renv::restore()`) |
| `requirements.txt` | Python packages for the verification and manuscript-table scripts |
| `data/raw/SOURCES.md`, `data/raw/MANIFEST.tsv` | Where each GWAS file comes from, access conditions and notes |
| `data/instruments/` | Instrument-selection summaries; LD-pruned instrument **rsID lists** (`ld_pruned/`). Per-variant effect files are not included (see below) |
| `results/tables/` | Derived study-level results (MR estimates, conditional F, diagnostics, overlap indicators, mediation, planning benchmarks, verification records) |
| `results/figures/` | Figures 1 and 2 |
| `manuscript/` | Scripts that build the supplementary tables and figures; `supplementary_tables.xlsx` (eTables 1–20); source and covariate tables |

## What is not included, and why

See `EXCLUDED.md` for the full list. This repository does not redistribute variant-level effect sizes from the source
GWAS, or derived per-variant outputs from which source effects could be reconstructed (single-SNP ratio estimates,
leave-one-out estimates per SNP, per-SNP Steiger variance terms, per-SNP outcome sample sizes, conditional-F input
matrices). The one exception is the effect allele, beta and standard error of the educational attainment instruments
(EA4, EA3) in `manuscript/tables/instrument_lists.tsv` and eTable 19, included with permission from the SSGAC. All
omitted files are regenerated by the pipeline from the source downloads.

## Reproducing the analysis

1. **Software.** R 4.5.3 with `renv::restore()`; PLINK v1.90b6.10 (clumping) and the 1000 Genomes Phase 3 EUR reference
   panel; Python 3.11 with `pip install -r requirements.txt`. LDSC was run through GenomicSEM (version in `renv.lock`).
2. **Data.** Obtain every file under its provider's terms; source GWAS files are not redistributed here. `R/01_download_sumstats.R`
   downloads most files automatically from the URLs in `data/raw/MANIFEST.tsv` (GWAS Catalog, Pan-UKB, DeSci Nodes,
   GLGC, GIANT, figshare, FinnGen and the MVP dbGaP FTP). The files below must be obtained separately and saved under
   the names the code expects (paths relative to the repository root; see also `data/raw/SOURCES.md`).

   *Click-through or request-form downloads (save in `data/raw/`):*

   | Dataset | Provider and access | Save as |
   |---|---|---|
   | EA4, excluding 23andMe [Okbay 2022] | SSGAC data portal, https://www.thessgac.org/data (registration and terms of use) | `Okbay 23andMe Additive Exclusion.txt.gz` |
   | EA3, excluding 23andMe [Lee 2018] | SSGAC data portal, https://www.thessgac.org/data | `Lee GWAS EA Excl 23andMe.txt` |
   | Household income [Hill 2019] | Edinburgh DataShare, https://datashare.ed.ac.uk/handle/10283/3441 (doi:10.7488/ds/2643) | `Hill Data/Household_Income_UKBiobank.txt.gz` |
   | Lifetime smoking index [Wootton 2020] | University of Bristol data.bris, doi:10.5523/bris.10i96zb8gm0j81yz0q6ztei23d | `Wootton Data/2019.10.02 Lifetime Smoking GWAS Data Sheet 1.txt` |
   | Type 2 diabetes, trans-ancestry [DIAMANTE, Mahajan 2022] | DIAGRAM consortium, https://diagram-consortium.org/downloads.html (free request form) | `DIAMANTE-TA.sumstat.txt` |

   *Open files not fetched by `01_download_sumstats.R` (save in `data/raw/`):*

   | Dataset | Source | Save as |
   |---|---|---|
   | CAD, European ancestry [Aragam 2022] | GWAS Catalog GCST90132314, `GCST90132314_buildGRCh37.tsv` (about 3.3 GB) | `cad_aragam2022_eur.tsv` |
   | Heart failure, MVP phecode 428, EUR | GWAS Catalog GCST90475981, `GCST90475981.tsv.gz` | `hf_mvp_phe428_EUR.gwascat.tsv.gz` |
   | Cerebral infarction, MVP phecode 433.21, EUR | GWAS Catalog GCST90477991, `GCST90477991.tsv.gz` | `stroke_mvp_phe433_21_EUR.gwascat.tsv.gz` |

   *Reference data (save in `data/reference/`):*

   | Resource | Source | Save as |
   |---|---|---|
   | 1000 Genomes Phase 3 LD reference (PLINK files) | MRC-IEU, http://fileserve.mrcieu.ac.uk/ld/1kg.v3.tgz | extract to `data/reference/1kg_v3/` |
   | European LD scores (`eur_w_ld_chr`, with `w_hm3.snplist`) | Zenodo record 8182036 (doi:10.5281/zenodo.8182036); the original Broad Institute URL now returns 404 | extract to `data/reference/eur_w_ld_chr/` |

   PLINK v1.90b6.10 is provided by the `plinkbinr` R package recorded in `renv.lock`. Checksums for the files used in
   the original analysis are in `data/raw/MANIFEST.tsv` and `data/raw/SOURCES.md`; the SHA-256 of each file in the two
   tables above matches its `MANIFEST.tsv` record.
3. **Run order.** `R/00_setup.R` is sourced by every script.
   - `01_download_sumstats.R`: automatic downloads and integrity checks.
   - `02_select_instruments.R`; `02b`–`02j`: feasibility, conditional-F verification, mediator strength, comparable-model
     pilot, qhet checks, van Zuydam SE scale, planning benchmarks, shared SES factor.
   - `03_harmonize.R`; `03b_verify_harmonization.R`; `03c_verify_source_rows.py`; `03d_ld_proxies.R`;
     `03e_verify_proxies.py`.
   - `04_run_mr_univariable.R` (run as a 96-cell array job in the original analysis); `04b_verify_presso_outliers.R`.
   - `05_mvmr_appraisal.R`; `06_mediation.R`; `07_overlap_indicators.R`.
   - `manuscript/build_data_source_table.py`, `manuscript/build_supplementary_tables.py`,
     `manuscript/verify_supplementary_tables.py`, `manuscript/describe_joint_sets.py`, `manuscript/make_figures.py`.

### Reproducibility status

- The results in `results/tables/` were produced by these scripts in the original working environment (local machine
  and a computing cluster for the univariable cells; two reference cells were reproduced across the two environments to
  a relative tolerance of 10⁻⁸).
- In a clean clone, all R scripts parse and `renv.lock` covers the packages they load. **This is a static check, not an
  end-to-end reproduction:** the full pipeline has not been re-run from a clean environment with freshly downloaded
  source files.
- MR-PRESSO and bootstrap steps are seeded; seeds are recorded in `results/tables/mr_univariable_cell_provenance.tsv`.
